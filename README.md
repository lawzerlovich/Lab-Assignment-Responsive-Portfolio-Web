# 🌐 More of Me – Personal Portfolio Website

## 📖 Project Overview

**More of Me** is a single-page personal portfolio website created as part of a lab assignment. The website showcases personal information, educational background, experience, projects, skills, personal strengths, weaknesses, and contact information.

The website is built using **HTML5, CSS3, and JavaScript** with a responsive layout, interactive elements, and a warm cream and dark espresso color theme.

## 👥 Target Audience

This portfolio is designed for:

- Potential employers and recruiters.
- People interested in my background and experience.
- Individuals interested in my projects, skills, and interests.

## 🧱 Technologies Used

- **HTML5** – Structures the website content and sections.
- **CSS3** – Handles the website styling, layout, colors, animations, and responsiveness.
- **JavaScript** – Adds interactive features such as theme switching, scroll animations, scroll progress tracking, and a back-to-top button.
- **Google Fonts (Nunito)** – Provides the typography used throughout the website.

## 🎨 Design & Styling

The website uses a warm and minimal visual design with two available themes:

- **Warm Cream Theme:** A light theme with soft cream backgrounds and dark brown text.
- **Dark Espresso Theme:** A dark theme with espresso-colored backgrounds and light text.

Additional styling features include:

- Rounded navigation buttons.
- Rounded content cards.
- Soft shadows.
- Hover effects.
- Smooth scrolling.
- Scroll-reveal animations.
- Responsive card layouts.

## ⚡ JavaScript Features

JavaScript is used to provide additional interactive functionality:

1. **Dark/Light Theme Toggle:** Allows users to switch between Warm Cream and Dark Espresso themes. The selected theme is saved using localStorage.
2. **Scroll Progress Bar:** Displays a progress bar at the top of the page to indicate how far the user has scrolled.
3. **Scroll-Reveal Animations:** Content cards smoothly appear when they enter the viewport using Intersection Observer.
4. **Back-to-Top Button:** A floating button appears when scrolling down and smoothly returns the user to the top of the page.

## 📱 Responsiveness

The website includes responsive styling to accommodate different screen sizes.

- Desktop
- Mobile and smaller screens (using CSS media queries)

The layout adjusts the navigation header, content spacing, and profile image container for smaller screens.
